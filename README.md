# BS.CK2. Đỗ Thanh Liêm — Personal Academic Website

Website cá nhân của **BS.CK2. Đỗ Thanh Liêm**, được xây dựng và triển khai bằng **GitHub Pages**.

🌐 Website:  
https://bsliem.github.io

Website nhằm giới thiệu thông tin chuyên môn, hoạt động nghiên cứu và định hướng học thuật trong các lĩnh vực:

- Y học cổ truyền  
- Thần kinh học  
- Sa sút trí tuệ  
- Đánh giá nhận thức lâm sàng  

---

# Mục tiêu của website

Website được xây dựng để:

- Giới thiệu hồ sơ chuyên môn của bác sĩ  
- Cung cấp thông tin nghiên cứu và dự án khoa học  
- Chia sẻ bài báo và tài liệu học thuật  
- Hỗ trợ liên hệ với bệnh nhân và đồng nghiệp  
- Xây dựng hồ sơ học thuật trực tuyến  

---

# Nội dung chính

Trang web hiện bao gồm các phần:

---

# Workflow phát triển

Quy trình làm việc của dự án:

```
RStudio
   ↓
Git commit
   ↓
Git push
   ↓
GitHub repository
   ↓
GitHub Pages
   ↓
Website online
```

Sau mỗi lần **commit và push**, website sẽ tự động cập nhật sau vài giây.

# Hướng phát triển tiếp theo

Các tính năng dự kiến sẽ được bổ sung:

- CSS stylesheet cho giao diện
- ảnh đại diện
- trang **research**
- trang **publications**
- trang **CV học thuật**
- liên kết **Google Scholar**
- liên kết **ORCID**
- danh sách công trình nghiên cứu
- tài liệu và slide bài giảng

Cấu trúc website dự kiến:

```

```
