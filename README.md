# BS.CK2. Đỗ Thanh Liêm – Personal Website

Website cá nhân và học thuật của **BS.CK2. Đỗ Thanh Liêm**.

Trang web được xây dựng bằng **Quarto** và xuất bản qua **GitHub Pages**.

**Website chính thức:**  
https://bsliem.github.io

---

## Mục tiêu website

Website được xây dựng nhằm:

- Giới thiệu **hồ sơ chuyên môn**
- Chia sẻ **bài viết và nghiên cứu**
- Cung cấp **thông tin đặt lịch khám**
- Tạo **kênh thông tin chính thức trên Internet**

Website phục vụ:

- người bệnh
- đồng nghiệp
- sinh viên y khoa
- cộng đồng quan tâm tới y học cổ truyền và sa sút trí tuệ

---

## Công nghệ sử dụng

Website sử dụng các công cụ sau:

- **Quarto** – xây dựng website từ Markdown / Quarto
- **Git** – quản lý phiên bản
- **GitHub** – lưu trữ source code
- **GitHub Pages** – xuất bản website
- **CSS tùy chỉnh** – thiết kế giao diện

### Workflow

```text
Quarto → Git → GitHub → GitHub Pages → Website
